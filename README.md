# LinkedIn Outreach Data Quality Audit – Capstone Project

## 1. About the Project

This Capstone project focuses on analysing and improving the quality of LinkedIn outreach data using Python. The project involves examining multiple datasets, including Invitations, Connections, and Messages, to identify data quality issues and prepare the data for further analysis.

The main objective is to identify missing values, duplicate records, inconsistencies, and other data-related issues to improve data accuracy, reliability, and usability.

## 2. My Role

I worked on the data quality auditing and cleaning process as part of this Capstone project.

My responsibilities included:
- Exploring and understanding the provided datasets.
- Identifying missing values and duplicate records.
- Checking data structure, column names, and data types.
- Developing Python code to examine data quality issues.
- Cleaning and validating data where required.
- Reviewing the results to understand the overall quality of the datasets.
